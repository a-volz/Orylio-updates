# Orylio Updates

Public signed update metadata for Orylio. Development sources are private.

The stable Sparkle feed is [appcast.xml](https://github.com/a-volz/Orylio-updates/releases/latest/download/appcast.xml).

The initial feed contains **no app release and no downloadable installer**. A future explicitly approved release will provide a signed/notarized common package for the Orylio menu-bar helper, native Mac photo viewer and Lightroom plugin, with the corresponding third-party sources and release manifest. Package installation requires administrator authorization. The common package targets Apple Silicon and macOS 26 or newer.

The XML feed is Ed25519-signed. Do not modify it without re-signing. No private keys, credentials, catalogs, photos or development sources belong in this repository.
